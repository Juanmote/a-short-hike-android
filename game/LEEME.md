# Archivos del juego

Esta carpeta está vacía a propósito: aquí van los archivos de **tu** copia de A Short Hike
(itch.io Linux o Steam Windows, versión 1.10.2), y **solo en tu copia privada** de este repositorio.

Sube un `.zip` o `.7z` con el contenido de la carpeta del juego (la que tiene la carpeta
`AShortHike_Data`). Si pesa más de 25 MB, la web de GitHub no te dejará subirlo aquí:
usa una release con la etiqueta `juego` (ver README).
